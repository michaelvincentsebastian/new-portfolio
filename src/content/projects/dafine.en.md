## General

### Problem

Data analysts and business teams routinely receive raw datasets riddled with inconsistencies: missing values, duplicate rows, mixed casing, whitespace noise, and outliers. Cleaning this data manually in spreadsheets is tedious, error-prone, and does not scale. Existing tools either require technical expertise or lock users into opaque black-box transformations with no visibility into what actually changed and why.

### User

Data analysts, business intelligence teams, non-technical business professionals, and product managers.

### Solution

Dafine (Data Refine) is a web-based AI-powered data cleaning and self-service analytics application. Users upload a raw data file, and the system automatically profiles each column, selects the appropriate cleaning strategy, generates SQL via AI, and returns a cleaned file — all without writing a single line of code.

### Key Features

- **Automated Deep Profiling** — Per-column statistical analysis including skewness, IQR, quartiles, outlier detection, categorical inference, and string quality checks, all computed before any AI is involved.
- **Intelligent NULL Imputation** — The system automatically selects the right strategy per column: mean for symmetric distributions, median for skewed ones, mode for categorical columns, and forward-fill for time-series.
- **AI-Powered SQL Cleaning** — Rather than sending raw data to the AI, Dafine sends pre-computed instructions. The AI's sole job is generating syntactically correct DuckDB SQL — making results auditable and consistent.
- **Interactive Chart Builder** — Dashboard page lets users build charts from cleaned data with filters, sorting, Top N, Group By, and multiple metrics — no SQL knowledge required.

### Challenge

Validating the safety of AI-generated SQL execution, ensuring in-memory DuckDB instances perform efficiently during concurrent raw file uploads, and securely encrypting user API keys.

### Impact

- **Zero code required** — any user can clean a dataset without SQL or Python knowledge.
- **Fully auditable** — every cleaning run stores the exact SQL executed and the AI's reasoning.
- **Statistically grounded** — cleaning decisions are derived from computed statistics, not AI guesswork.

## Technical

### Explanation

Dafine splits the work between an interactive frontend and a high-performance Python backend. ephemereal DuckDB in-memory databases process datasets dynamically, using metadata persisted in a Supabase PostgreSQL instance.

### Architecture

1. **File Ingestion** — Raw files are uploaded and loaded dynamically as views in an in-memory DuckDB session.
2. **Statistical Profiling** — DuckDB executes analytical queries to compute column profiles, distribution metrics, and imputation targets.
3. **Prompt Compilation** — A payload of column profiles and translation instructions is prepared and sent to the LLM.
4. **Execution & Export** — The returned SQL statement is validated, run against the DuckDB source view, and outputted to the requested file format.

### Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript, Tailwind CSS, Chart.js
- **Backend Framework**: FastAPI (Python)
- **Data Processing**: DuckDB (in-memory)
- **Database & Auth**: Supabase PostgreSQL & Supabase Auth
- **Storage**: Supabase Object Storage (Parquet exports)
- **LLM Integration**: OpenRouter API (Gemini/Claude/GPT models)

### Data Sources

- CSV, Parquet, and Excel (.xlsx, .xls) uploads
- SQLite database uploads

### Repository Structure

- `frontend/` — Single Page Application assets (HTML, CSS, JS)
- `backend/` — FastAPI application structure
  - `data_profiler.py` — DuckDB statistics and distribution profiling logic
  - `ai_cleaner.py` — Prompt compiling and OpenRouter integration
  - `main.py` — Server entry point and API routes
- `docker-compose.yml` — Local development container configuration

### Features

- DuckDB in-memory session confinement per-request
- AES-256-GCM encryption for stored user API keys
- Outlier tracking using IQR (Tukey's fences)

## Result

### Metrics

- **100%** transparency: Users can view and copy the raw SQL generated by the AI agent for audits.
- **0%** raw data leak: Source dataset values are never sent to external LLMs; only structural metadata and profile distributions are shared.
- Automated chart builder renders instantly via DuckDB client queries.
